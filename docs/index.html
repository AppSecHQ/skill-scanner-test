What this site is

skillscan.io publishes what an automated scanner finds in the skills people actually install from skills.sh, ClawHub and other sources, plus a scan history per skill so drift is visible. It is not a benchmark of scanners (that is skillscan.sh) and it is unrelated to the SkillScan career assessment. Read the methodology and limitations before treating any verdict as final, and download the dataset if you want to check our work.
