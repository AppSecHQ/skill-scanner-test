Verdict safe, but 2 findings (2 medium), mainly social engineering. Most recent scan 2026-02-07.

This skill package has MEDIUM severity issues primarily related to deceptive presentation. The skill masquerades as an agent capability but actually describes an external npm CLI tool ('npx ai-webhook'), making it misleading to users who expect agent skills to extend the AI assistant's direct capabilities. The package contains no executable scripts (Python/Bash) and instead provides documentation for a Node.js command-line tool. Additionally, the skill includes promotional content for LXGIC Studios' developer toolkit, which is inappropriate for agent skill packages. While there are no critical security threats like data exfiltration or command injection (since there's no executable code), the deceptive nature of the skill description and the promotional content constitute social engineering concerns. The skill also has minor issues with missing referenced files and incomplete metadata. This appears to be either a misunderstanding of what agent skills are, or an attempt to use the agent skills ecosystem for promotional purposes rather than providing genuine agent capabilities.

Findings

MEDIUM Deceptive Skill Description - External Tool Masquerading as Agent Skill Social Engineeringllm

The skill description and instructions describe an external npm package ('npx ai-webhook') rather than an agent skill that the AI assistant can execute. The entire SKILL.md contains instructions for a command-line tool that requires Node.js and npm, not instructions for the agent to follow. This is misleading because users expect agent skills to extend the agent's capabilities directly, not to be documentation for external tools. The skill appears to be promotional content for LXGIC Studios' developer toolkit rather than a functional agent skill.

SKILL.md

Quick Start section shows 'npx ai-webhook "stripe payment succeeded"' - this is an external npm command, not an agent capability. The entire document describes CLI usage patterns, npm installation, and external tool features rather than agent instructions.
Remediation: Either: (1) Convert this into an actual agent skill with Python/Bash scripts that implement webhook generation logic the agent can execute, or (2) Clearly label this as documentation/reference material rather than an executable skill. Remove misleading skill metadata that suggests this extends agent capabilities.
MEDIUM Promotional Content Disguised as Functional Skill Social Engineeringllm

The skill contains extensive promotional content for LXGIC Studios ('Part of the LXGIC Dev Toolkit', 'This is one of 110+ free developer tools built by LXGIC Studios', links to GitHub, Twitter, Substack, website). This promotional material is embedded within what appears to be a functional skill description, which is misleading. Agent skills should focus on providing capabilities to the agent, not serving as advertisement platforms.

SKILL.md

Section titled 'Part of the LXGIC Dev Toolkit' contains: 'This is one of 110+ free developer tools built by LXGIC Studios. No paywalls, no sign-ups, no API keys on free tiers. Just tools that work.' followed by multiple promotional links.
Remediation: Remove promotional content from the skill instructions. If attribution is needed, limit it to a brief author/source line in the YAML frontmatter. Agent skills should be functional tools, not marketing materials.
