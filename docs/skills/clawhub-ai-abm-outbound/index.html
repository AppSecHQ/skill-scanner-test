What this skill does

Multi-channel ABM automation that turns LinkedIn URLs into coordinated outbound campaigns. Scrapes profiles, enriches with Apollo (email + phone), gets mailing addresses via Skip Trace, then orchestrates email sequences, LinkedIn touches, and handwritten letters via Scribeless. The secret weapon for standing out in crowded inboxes.

CRITICAL Hardcoded API Keys Required in Environment Variables Data Exfiltrationllm

The skill requires users to export sensitive API keys (APIFY_API_KEY, APOLLO_API_KEY, SCRIBELESS_API_KEY) as environment variables. This creates multiple security risks: (1) API keys stored in shell history files, (2) Keys accessible to all processes running under the user account, (3) No secure credential management, (4) Keys may be logged or exposed in process listings. The skill provides no guidance on secure credential storage or rotation.

SKILL.md

```bash
export APIFY_API_KEY="your_key"
export APOLLO_API_KEY="your_key"
export SCRIBELESS_API_KEY="your_key"
```
Remediation: Implement secure credential management: (1) Use a credential manager (e.g., system keychain, AWS Secrets Manager, HashiCorp Vault), (2) Never store credentials in environment variables or shell history, (3) Implement credential rotation policies, (4) Use least-privilege API keys with minimal scopes, (5) Add instructions for secure credential handling in the skill documentation.
CRITICAL Mass Personal Data Collection and Exfiltration Pipeline Data Exfiltrationllm

The skill orchestrates a comprehensive personal data collection pipeline that scrapes LinkedIn profiles, enriches with contact information (emails, phone numbers), obtains physical mailing addresses via skip tracing, and transmits all data to multiple third-party services (Apify, Apollo, Scribeless). This creates severe privacy and data protection risks: (1) Bulk collection of personal identifiable information (PII) without explicit consent, (2) Cross-service data sharing with multiple vendors, (3) Physical address lookup via skip tracing services, (4) No data retention or deletion policies, (5) Potential violations of GDPR, CCPA, and other privacy regulations, (6) No user consent mechanisms for data subjects.

SKILL.md

Pipeline stages: LinkedIn scraping → Email/phone enrichment (Apollo) → Physical address lookup (Skip Trace) → Multi-channel outreach (email, LinkedIn, physical mail). Example: 'curl -X POST "https://api.apify.com/v2/acts/one-api~skip-trace/run-sync-get-dataset-items"' for obtaining physical addresses.
Remediation: (1) Implement explicit consent mechanisms for all data collection, (2) Add data protection impact assessment (DPIA) requirements, (3) Implement data minimization principles - only collect necessary data, (4) Add data retention and deletion policies, (5) Provide opt-out mechanisms for data subjects, (6) Add legal compliance warnings (GDPR, CCPA, CAN-SPAM, TCPA), (7) Implement audit logging for all data access and transmission, (8) Add geographic restrictions based on privacy law jurisdictions, (9) Require legal review before deployment.
