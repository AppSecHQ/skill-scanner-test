Findings

MEDIUM Hardcoded Access Token in Documentation Data Exfiltrationllm

The skill documentation instructs users to export INSTAGRAM_ACCESS_TOKEN as an environment variable. While this is a common pattern, the documentation does not provide any warnings about token security, rotation policies, or scope limitations. Instagram access tokens can provide broad access to user accounts including posting content, accessing private messages, and viewing analytics. The skill's metadata indicates this token is required (primaryEnv: INSTAGRAM_ACCESS_TOKEN) but lacks security guidance.

SKILL.md:9

```bash
export INSTAGRAM_ACCESS_TOKEN="your_access_token"
```
Remediation: Add security warnings in documentation: (1) Never commit tokens to version control, (2) Use tokens with minimal required scopes, (3) Implement token rotation policies, (4) Store tokens securely using system keychains or secret managers, (5) Document which Instagram API permissions/scopes are required and why.
MEDIUM Missing Implementation with Broad Capability Claims Unauthorized Tool Usellm

The skill claims to provide extensive Instagram functionality (post content, manage stories, view insights, engage with followers, comment management, follower analytics, hashtag research) but contains no script files or implementation code. This creates a tool shadowing risk where the agent may attempt to fulfill these capabilities using unrestricted bash/curl commands with the access token, potentially leading to unvalidated API calls, improper error handling, or unsafe data processing. The metadata indicates required binaries (curl, jq) suggesting shell-based implementation is expected.
