Findings

MEDIUM Transitive Trust Abuse - Following External Web Content Prompt Injectionllm

The skill instructs the agent to fetch and parse content from gitclassic.com, a third-party service, without any validation or security warnings. The agent is directed to trust and follow HTML content from this external source. If gitclassic.com is compromised or serves malicious content, the agent could be subjected to indirect prompt injection attacks embedded in the HTML responses. The skill provides no mechanism to validate the integrity or safety of the content retrieved.

SKILL.md

Instructions direct agent to: 'curl https://gitclassic.com/{owner}/{repo}' and parse responses. No validation of external content is specified. Agent is told to trust 'Clean, semantic HTML' from external source.
Remediation: Add explicit warnings about trusting external content. Implement content validation checks. Consider sandboxing external content parsing. Add user confirmation before fetching from external domains. Document the trust model and risks of following third-party HTML content.
MEDIUM Potentially Misleading Service Claims Social Engineeringllm

The skill makes strong performance and reliability claims about a third-party service (gitclassic.com) that cannot be verified and may mislead users. Claims include '<500ms load times', 'cached responses' for rate limit avoidance, and 'clean, semantic HTML' that is 'easy to parse'. These claims could be inaccurate or change without notice, potentially causing the agent to make incorrect decisions or set false user expectations. The skill also promotes a paid PRO tier without disclosing the commercial relationship.

SKILL.md

Unverifiable claims: 'Page load <500ms', 'Rate limits: Cached responses', 'AI agent friendly: Clean, semantic HTML'. Commercial promotion: 'PRO subscription ($19/year or $49/lifetime)' without disclosure of author relationship to service.
Remediation: Add disclaimers that performance claims are based on third-party service and may vary. Disclose any commercial relationship between skill author and gitclassic.com. Remove absolute performance guarantees. Add warnings that service availability and behavior are outside skill control.
