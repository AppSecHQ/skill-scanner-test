Findings

MEDIUM Misleading Skill Description - External Tool Masquerading as Agent Skill Social Engineeringllm

The skill presents itself as an agent skill package but actually describes an external npm package ('npx ai-landing'). The SKILL.md contains no agent instructions, only documentation for a separate command-line tool. This is deceptive because users expect agent skills to provide instructions the agent follows, not documentation for external tools. The skill cannot function as described since it requires 'npx' execution and OPENAI_API_KEY, which are not part of the agent skill framework.

Quick Start section shows 'npx ai-landing' commands, Requirements mention 'Node.js 18+' and 'OPENAI_API_KEY required', but no agent instructions are provided for how the agent should use this skill.
Remediation: Either: (1) Rewrite as a proper agent skill with instructions for the agent to generate landing pages directly, or (2) Clearly state in the description that this is documentation for an external tool, not a functional agent skill. Add proper agent instructions if intended as a skill.
MEDIUM Missing Referenced Script File Unauthorized Tool Usellm

The skill references 'description.py' in its instructions but this file is not included in the skill package. This creates a broken dependency that prevents the skill from functioning. If description.py was intended to contain malicious code, its absence prevents detection. If it's a legitimate component, the skill is incomplete and non-functional.

Referenced Files section shows 'description.py (not found)'. The file is mentioned but not provided in the package.
Remediation: Include the description.py file in the skill package if it's required for functionality. If the reference is erroneous, remove it from the documentation. Ensure all referenced files are present and their purpose is clearly documented.

  • Static analyzer. Pattern rules over SKILL.md and bundled files: known-bad commands, exfiltration URLs, secrets, obfuscation.
