Command Injection

397 findings 152 skills affected OWASP AST01: Malicious Skillsalso AST03also AST06

The skill instructs the agent to run shell commands, downloads and executes remote code, pipes untrusted input into a shell, or includes install steps such as 'curl | sh' from unpinned sources. Even when intentional, these give an attacker who controls the remote resource code execution on the user's machine.
