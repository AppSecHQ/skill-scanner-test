Tool Chaining Abuse

30 findings 2 skills affected OWASP AST03: Over-Privileged Skillsalso AST06also AST01

Individually acceptable tool calls combined into a harmful sequence: read a secret, then write it to a file, then commit and push. Each step passes review in isolation. The CompoSkill and ColluSkill research shows this also evades scanners that score skills one at a time.
