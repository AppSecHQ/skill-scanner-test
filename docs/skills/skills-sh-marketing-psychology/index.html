Findings

MEDIUM Transitive Trust Abuse via External Product Marketing Context File Prompt Injectionllm

The skill instructions direct the agent to read and trust content from `.claude/product-marketing-context.md` without validation. This file is external to the skill package and could contain malicious instructions that override the skill's intended behavior. The instruction 'Check for product marketing context first: If `.claude/product-marketing-context.md` exists, read it before applying mental models. Use that context to tailor recommendations' creates a transitive trust relationship where the skill delegates authority to untrusted external content.

SKILL.md

Check for product marketing context first:
If `.claude/product-marketing-context.md` exists, read it before applying mental models. Use that context to tailor recommendations to the specific product and audience.
Remediation: Remove the instruction to automatically read external context files, or implement strict validation if external context is necessary. Consider: (1) Bundling context files within the skill package instead of reading from external locations, (2) Adding explicit warnings that external files should be user-verified, (3) Implementing content validation before processing external files, (4) Requiring user confirmation before reading external context files.
