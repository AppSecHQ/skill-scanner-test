What this skill does

Generate publication-quality chart images from data. Supports line, bar, area, point, candlestick, pie/donut, heatmap, multi-series, and stacked charts. Use when visualizing data, creating graphs, plotting time series, or generating chart images for reports/alerts. Designed for Fly.io/VPS deployments - no native compilation, no Puppeteer, no browser required. Pure Node.js with prebuilt binaries.

MEDIUM External Dependency Installation Without Version Pinning Resource Abusellm

The skill instructions require running 'npm install' in the scripts directory without specifying exact package versions or providing a package.json file for review. This creates supply chain risks as dependencies could be updated to malicious versions between installations. The skill claims to use Sharp and Vega-Lite but no package.json was provided for verification.

Remediation: Include package.json and package-lock.json files in the skill package with pinned versions. Provide these files for security review. Use exact versions (e.g., 'sharp': '0.33.0') rather than version ranges.
