The Taskr skill presents MODERATE security concerns primarily related to data transmission and credential management. The skill functions as a cloud-based task tracking system that sends project data to an external API (taskr.one) without explicit user consent or privacy disclosures. While the service appears legitimate, users may unknowingly transmit sensitive project information, code context, and work patterns to third-party servers. The API key management approach stores credentials in configuration files without security guidance, creating exposure risks. The skill lacks critical metadata (license, compatibility) and has incomplete setup instructions. However, no active malicious behavior, prompt injection, or code execution vulnerabilities were detected. The skill appears to function as described, but requires better transparency about data handling and security practices.

MEDIUM Hardcoded External API Endpoint Without Verification Data Exfiltrationllm

The skill hardcodes an external API endpoint (https://taskr.one/api/mcp) that will receive all task data, notes, and potentially sensitive project information. While this appears to be the legitimate Taskr service, there is no mechanism to verify the endpoint's authenticity or warn users about data transmission to third-party servers. Users may unknowingly send sensitive project details, code context, and work patterns to an external service.

```json
  "skills": {
    "entries": {
      "taskr": {
        "env": {
          "MCP_API_URL": "https://taskr.one/api/mcp",
```
Remediation: 1. Add explicit disclosure in the description that this skill transmits data to external servers 2. Include privacy policy link and data handling information 3. Warn users during setup about what data will be transmitted 4. Consider adding opt-in consent for data transmission 5. Document what data is sent to the external API
MEDIUM User API Key Exposure Risk Data Exfiltrationllm

The skill requires users to provide their API key (MCP_USER_API_KEY) through configuration, which will be stored in the gateway config. The instructions direct users to obtain this key from the Taskr web interface but provide no guidance on secure storage, rotation, or scope limitations. If the gateway config is compromised or accidentally shared, the API key could enable unauthorized access to the user's Taskr account and all associated project data.
