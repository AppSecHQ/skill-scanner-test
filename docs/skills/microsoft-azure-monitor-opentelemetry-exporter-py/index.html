Findings

MEDIUM Hardcoded Connection String with Instrumentation Key in Examples Data Exfiltrationllm

The skill documentation contains multiple code examples with placeholder connection strings that include 'InstrumentationKey=xxx'. While these are examples, they demonstrate a pattern of hardcoding sensitive credentials directly in code rather than exclusively using environment variables. This could encourage users to hardcode actual connection strings containing sensitive instrumentation keys, leading to credential exposure if code is committed to version control or shared.

connection_string="InstrumentationKey=xxx;..." appears in multiple code examples throughout the documentation
Remediation: Update all code examples to exclusively demonstrate environment variable usage (APPLICATIONINSIGHTS_CONNECTION_STRING) and add explicit warnings against hardcoding connection strings. Include a security best practices section emphasizing credential management.
MEDIUM Network Data Transmission to External Azure Endpoints Data Exfiltrationllm

The skill facilitates transmission of telemetry data (traces, metrics, logs) to external Azure Application Insights endpoints (IngestionEndpoint=https://xxx.in.applicationinsights.azure.com/). While this is the intended functionality, the skill collects and transmits potentially sensitive application data including logs, traces, and metrics to external Microsoft-controlled infrastructure. Users may inadvertently export sensitive information, credentials, or proprietary data through logging statements or trace attributes without proper data sanitization.

APPLICATIONINSIGHTS_CONNECTION_STRING=InstrumentationKey=xxx;IngestionEndpoint=https://xxx.in.applicationinsights.azure.com/ - All exporters send data to external Azure endpoints
Remediation: Add prominent security warnings about data sensitivity. Document data sanitization best practices. Recommend implementing custom processors to filter sensitive data before export. Advise users to review what data is being collected and ensure compliance with data governance policies.
