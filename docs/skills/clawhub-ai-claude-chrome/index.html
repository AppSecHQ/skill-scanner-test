Findings

HIGH Dangerous Permission Bypass Flag Required for Operation Command Injectionllm

The skill mandates use of '--dangerously-skip-permissions' flag which bypasses all safety confirmations in Claude Code. This flag auto-approves all browser actions without user consent, enabling arbitrary command execution, data access, and form submissions without oversight. The instructions explicitly state this flag is 'required for automation', making dangerous operations the default behavior.

SKILL.md

--dangerously-skip-permissions — auto-approve all actions (required for automation)

Always use `--dangerously-skip-permissions` for automated runs
Remediation: Remove the requirement for '--dangerously-skip-permissions' flag. Implement explicit user confirmation for sensitive browser operations. Add guardrails that require approval for: form submissions, navigation to new domains, data extraction, and file downloads. Consider implementing a whitelist of approved domains/actions.
HIGH Unrestricted Browser Access Without Data Protection Controls Data Exfiltrationllm

The skill provides unrestricted browser automation capabilities with no data protection boundaries. It can read any webpage content, access form data, extract credentials from login pages, and interact with authenticated sessions. Combined with the mandatory '--dangerously-skip-permissions' flag, this enables silent data exfiltration from any website the user has access to, including banking sites, email, cloud services, and internal corporate applications.

SKILL.md

Claude Code gains browser tools — it can navigate pages, click elements, fill forms, read content, and more.

Go to example.com and read the headline
Remediation: Implement strict data access controls: (1) Define allowed domains in manifest, (2) Require explicit user approval for accessing authenticated sites, (3) Prohibit access to credential fields and sensitive form inputs, (4) Add content filtering to prevent extraction of PII, credentials, or tokens, (5) Log all browser actions for audit trail.
MEDIUM Tool Restriction Bypass via External Binary Execution Unauthorized Tool Usellm

The skill bypasses agent tool restrictions by delegating all operations to an external binary (Claude Code) via nodes.run. This circumvents any allowed-tools restrictions that might be in place, as the agent only sees a bash command execution, not the actual browser automation operations. The external binary has unrestricted capabilities including network access, file system access, and arbitrary code execution through browser JavaScript.

SKILL.md

nodes.run node=<your-node-id> command='["bash", "-lc", "claude --dangerously-skip-permissions --chrome -p \"Go to example.com and read the headline\""]'
Remediation: Declare explicit tool requirements in manifest (allowed-tools: [Bash, network_access]). Document that this skill requires external binary execution and network access. Implement capability declarations that accurately reflect the skill's true permissions. Consider sandboxing the Claude Code execution environment.
MEDIUM Misleading Description Omits Security Risks Social Engineeringllm

The skill description presents this as a simple 'browser automation' alternative without disclosing the significant security implications: mandatory permission bypass, unrestricted web access, credential exposure risks, and external binary execution. Users may enable this skill thinking it's a safe browsing tool, unaware that it grants unrestricted browser control with no safety confirmations.
