The npkill skill is a legitimate utility for cleaning up Node.js build artifacts, but has moderate security and documentation concerns. The primary issues are: (1) lack of explicit tool declarations despite heavy bash command usage, (2) documentation of a potentially dangerous automated deletion command without enforcement of safety checks, (3) confusing references to non-existent Python files, and (4) missing optional metadata. The skill does not contain malicious code, data exfiltration, or prompt injection attempts. The skill would benefit from explicit tool declarations, removal of the automated deletion example or stronger safety enforcement, and cleanup of erroneous file references.

What this skill does

Clean up node_modules and .next folders to free up disk space using npkill. Specifically designed to help JavaScript and Next.js developers remove accumulated build artifacts that consume significant storage. Provides both interactive and automated cleanup options with safety checks to protect important system directories.

Findings

MEDIUM Potentially Dangerous Automated Deletion Command Resource Abusellm

The skill documents an automated deletion command 'npkill --delete-all --yes' that bypasses all confirmations and deletes all found node_modules folders without user review. While the instructions include a warning 'Use with Caution', the agent could execute this command if instructed, potentially causing unintended data loss. The skill encourages using dry-run first, but there's no enforcement mechanism to prevent immediate execution of the destructive command.

SKILL.md

### Automated Cleanup (Use with Caution)
```bash
npkill --delete-all --yes
```
Automatically deletes all node_modules folders found. Use only after verifying with dry-run.
Remediation: Consider removing the automated deletion example entirely, or add explicit instructions that the agent must ALWAYS run dry-run first and require explicit user confirmation before executing any deletion commands. Implement a multi-step workflow that enforces safety checks.
