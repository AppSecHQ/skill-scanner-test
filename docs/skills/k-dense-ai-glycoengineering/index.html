What this skill does

Analyzes and engineers protein glycosylation by scanning canonical N-glycosylation sequons, describing S/T-rich regions, checking curated glycan evidence, and preparing NetNGlyc, NetOGlyc and GlycoSHIELD workflows. Use for glycoprotein engineering, antibody Fc glycosylation, glycan shielding, and site-specific glycoproteomics interpretation.

Compatibility
Local sequence helpers require Python 3.10+. Public GlyTouCan lookup requires requests and network access. DTU predictors use a browser; optional GlycoSHIELD needs a separate source installation, glycan libraries, and GROMACS for SASA analysis.

SKILL.md covers: Glycoengineering · When to use · Workflow · Local sequence analysis · Three intended changes: A1N, P2A, A3T. P->A must be explicit. · Density is a fraction of residues, not an O-glycosylation probability. · Prediction services · Structural shielding with GlycoSHIELD · Database evidence and glycan notation · Antibody engineering decisions · Experimental interpretation and verification boundary
