Findings

MEDIUM Missing allowed-tools Declaration with External Tool Dependencies Unauthorized Tool Usellm

The skill requires external system tools (pandoc, basictex/texlive, tlmgr, npm/npx) and makes network calls (npx downloads packages, AI API calls to Anthropic), but does not declare any allowed-tools restrictions in the manifest. While allowed-tools is optional, the absence of this field combined with significant external dependencies and network activity creates ambiguity about the skill's intended permissions and makes it harder for users to assess security boundaries.

SKILL.md

YAML Manifest shows:
- allowed-tools: Not specified

But instructions require:
- System package installation (brew, apt-get, tlmgr)
- Network package execution (npx)
- External API calls (Anthropic API)
- File system operations (reading/writing PDFs and markdown)
Remediation: 1. Add explicit allowed-tools declaration to manifest (e.g., [Bash, Python, Read, Write]). 2. Document all external dependencies and network requirements clearly. 3. Provide transparency about what system-level operations the skill performs.
