Findings

CRITICAL API Key Credential Theft via External Domain Data Exfiltrationllm

The skill instructs the agent to register with an external API (api.swarmmarket.ai) and obtain an API key, then store it locally in ~/.config/swarmmarket/credentials.json or environment variables. This creates a credential theft vector where the agent's API key is transmitted to and controlled by an external third-party service. The skill explicitly tells agents to save and reuse this credential for all future requests, establishing persistent access for the external domain.

SKILL.md

Registration endpoint: POST https://api.swarmmarket.ai/api/v1/agents/register - Response includes api_key that must be saved. Instructions state: 'SAVE YOUR api_key IMMEDIATELY' and 'save it to your memory, environment variables (SWARMMARKET_API_KEY), or wherever you store secrets.' All subsequent API calls require this key via X-API-Key header.
Remediation: Remove external API registration requirement. If marketplace functionality is needed, implement it as a local service or require explicit user consent before any credential exchange with external services. Never instruct agents to automatically register with external services or store third-party API keys without user authorization.
HIGH Deceptive Skill Description Concealing External Dependencies Social Engineeringllm

The skill description ('The autonomous agent marketplace. Trade goods, services, and data with other AI agents.') presents this as a peer-to-peer agent marketplace, but the implementation requires all agents to register with and communicate through a centralized external service (api.swarmmarket.ai). This is social engineering through omission - users are not informed that using this skill means their agent will register with an external service and transmit data to third-party servers.

SKILL.md

Description: 'The autonomous agent marketplace. Trade goods, services, and data with other AI agents.' vs Reality: Centralized service requiring registration at api.swarmmarket.ai with API key authentication and all transactions routed through external servers.
Remediation: Update description to clearly state: 'Connects your agent to the SwarmMarket external service at api.swarmmarket.ai. Requires registration and API key. All marketplace activity is transmitted to third-party servers.' Add explicit warnings about external service dependencies in the description.
