This Telegram CLI skill presents MODERATE security risks primarily related to data access and credential management. The skill provides legitimate functionality for interacting with Telegram via a third-party CLI tool (@cyberdrk/tg), but lacks important security safeguards. Key concerns include: (1) No guidance on secure credential storage for Telegram API tokens, (2) Unrestricted access to all user Telegram data without access controls, (3) Missing security documentation about the implications of granting API access, (4) Hardcoded developer paths that expose unnecessary information. The skill does not contain malicious code, prompt injection attempts, or data exfiltration mechanisms. However, the broad data access capabilities combined with insufficient security guidance create risks if the agent or user environment is compromised. The skill would benefit from adding security warnings, implementing access controls, and providing clear documentation about credential management.

Findings

MEDIUM Telegram API Credentials Required Without Security Guidance Data Exfiltrationllm

The skill requires users to obtain Telegram API credentials from my.telegram.org/apps and authenticate via 'tg auth' command, but provides no security guidance on credential storage, session management, or the security implications of granting API access. The underlying CLI tool will store authentication tokens locally, creating potential credential exposure risks if not properly secured.

SKILL.md

First-time setup requires API credentials from https://my.telegram.org/apps

```bash
tg auth
```
Remediation: Add security warnings about: (1) Credential storage location and permissions, (2) Session token security, (3) Risks of using API credentials vs bot tokens, (4) Recommendation to use application-specific passwords if available, (5) Instructions for revoking access if compromised.
MEDIUM Unrestricted Access to Sensitive Telegram Data Data Exfiltrationllm

The skill provides broad access to read all Telegram messages, contacts, group memberships, and admin status without any access controls or data minimization principles. Commands like 'tg inbox', 'tg chats', 'tg read', and 'tg search --all' can access the user's entire Telegram history. While this matches the stated functionality, there are no safeguards against over-collection or unauthorized access if the agent is compromised.

SKILL.md

tg inbox                               # Unread messages summary
tg chats                               # List all chats
tg read "ChatName" -n 50               # Read last 50 messages
tg search "query" --all                # Search all chats
Remediation: Add security recommendations: (1) Implement read-only mode by default, (2) Require explicit user confirmation before accessing sensitive chats, (3) Add rate limiting to prevent bulk data extraction, (4) Log all access operations for audit purposes, (5) Consider implementing chat whitelisting to restrict which conversations can be accessed.
