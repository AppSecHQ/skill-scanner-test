The x-api skill presents MODERATE security risks primarily related to credential management and supply chain security. The skill's core functionality (posting to X/Twitter via official API) is legitimate, but the implementation guidance creates significant credential exposure risks through plaintext storage and unsecured environment variables. The external npm dependency without version pinning introduces supply chain vulnerabilities. No prompt injection, data exfiltration, or malicious code patterns were detected in the instructions. The skill would benefit from secure credential storage recommendations, dependency pinning, and better error handling guidance. Missing optional metadata fields reduce transparency but don't pose security threats.

Findings

HIGH Hardcoded Credential Storage in Plaintext Configuration File Data Exfiltrationllm

The skill instructs users to store sensitive X/Twitter API credentials (API keys, secrets, access tokens) in a plaintext JSON file at ~/.clawdbot/secrets/x-api.json without encryption or secure storage mechanisms. This creates a significant data exposure risk as these credentials provide full read-write access to the user's X/Twitter account.

SKILL.md

Config file at ~/.clawdbot/secrets/x-api.json containing consumerKey, consumerSecret, accessToken, accessTokenSecret in plaintext JSON format
Remediation: Implement secure credential storage using system keychains (macOS Keychain, Windows Credential Manager, Linux Secret Service). Alternatively, use encrypted credential storage with proper key management, or rely solely on environment variables with clear warnings about credential security.
MEDIUM External Dependency Without Integrity Verification Unauthorized Tool Usellm

The skill requires installing 'twitter-api-v2' npm package globally without version pinning, integrity checks, or provenance verification. This creates supply chain risks including package substitution, typosquatting, or malicious updates. Global installation also affects the entire system rather than being isolated to the skill.

SKILL.md

npm install -g twitter-api-v2 without version specification or integrity hash
Remediation: Pin to specific version (e.g., twitter-api-v2@1.15.2), include integrity hash verification, specify package scope (@latest from official registry), use local installation instead of global (-g flag), and verify package authenticity before installation.
