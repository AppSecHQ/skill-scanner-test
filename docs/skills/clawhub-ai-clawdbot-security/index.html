Findings

MEDIUM Misleading Skill Description - Not an Agent Skill Social Engineeringllm

This package is NOT an Agent Skill but rather an npm package (npx clawdbot-security-audit). The skill description claims to provide 'Security audit and hardening for Clawdbot/Moltbot installations' but the instructions only contain documentation for running an external npm tool. There is no SKILL.md with agent instructions, no Python/Bash scripts for the agent to execute, and no actual skill functionality. This is deceptive packaging that could mislead users about what they're installing.

Instructions contain 'npx clawdbot-security-audit' commands but no agent-executable code or actual skill logic. The entire content is documentation for an external tool, not agent instructions.
Remediation: Either: (1) Remove this from the agent skills repository as it's not a skill, or (2) Rewrite as an actual agent skill with proper YAML frontmatter, agent instructions, and executable scripts that perform the security audit using agent tools (Read, Bash, Python).

What we checked

  • Static analyzer. Pattern rules over SKILL.md and bundled files: known-bad commands, exfiltration URLs, secrets, obfuscation.
  • Behavioral analyzer. Checks what the skill asks the agent to do against what its description claims it does.
  • Llm analyzer. A language model reads the skill and reports intent-level issues the rules cannot express.
  • Trigger analyzer. Looks for instructions that fire on conditions the user did not ask for.
  • Meta analyzer. A second model pass that validates, deduplicates and re-scores the other analyzers' findings.

What we did not check

  • Runtime behaviour. The skill was not executed; findings come from reading its files.
  • Anything fetched at install or run time, including remote scripts, package dependencies, and URLs the skill tells the agent to open.
  • Content the analyzers cannot read: images, binaries, and some non-English text.
