The Streme Token Launcher skill is a specialized tool for deploying tokens on the Base blockchain via Streme contracts. The skill itself does not contain malicious code, scripts, or direct security threats. However, it has several security and documentation concerns: (1) Code examples encourage direct private key handling without adequate security warnings, (2) Missing critical manifest metadata reduces transparency, (3) Incomplete documentation with broken file references, and (4) Lack of security guidance for external API credential management. The skill appears legitimate in purpose but needs improved security documentation and complete metadata to help users implement it safely. No data exfiltration, prompt injection, or command injection threats detected. Primary risks are around user implementation security rather than the skill itself being malicious.

Findings

MEDIUM Hardcoded Private Key Risk in Code Examples Data Exfiltrationllm

The instruction body contains TypeScript examples that import 'privateKeyToAccount' from 'viem/accounts', suggesting users will handle private keys directly. While no actual private keys are hardcoded, the pattern encourages insecure key management practices. Users may hardcode private keys in their implementation following these examples, leading to credential exposure.

SKILL.md:7

import { privateKeyToAccount } from 'viem/accounts';
Remediation: Add explicit warnings about private key security. Recommend using environment variables, hardware wallets, or secure key management services. Include example: 'const account = privateKeyToAccount(process.env.PRIVATE_KEY as `0x${string}`);' with security best practices documentation.
