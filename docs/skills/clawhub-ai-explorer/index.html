Findings

MEDIUM Optional GitHub Token Usage Without Security Guidance Data Exfiltrationllm

The skill requests users to configure a GITHUB_TOKEN environment variable and provides instructions to add it to ~/.zshrc. While the token is optional and used legitimately for API rate limiting, the instructions lack security guidance about token permissions, scope limitations, or secure storage practices. Users may inadvertently create tokens with excessive permissions or store them insecurely.

SKILL.md

```bash
# 获取 Token: https://github.com/settings/tokens
export GITHUB_TOKEN="your_github_token"
```

Adds to ~/.zshrc:
```bash
echo 'export GITHUB_TOKEN="your-token"' >> ~/.zshrc
```
Remediation: Add security guidance: (1) Specify minimum required token scopes (public_repo read-only access), (2) Warn against using tokens with write permissions, (3) Recommend using GitHub CLI or credential managers instead of plaintext environment variables, (4) Include token rotation best practices.
LOW Unbounded API Requests Without Rate Limiting Resource Abusellm

The script makes GitHub API requests without implementing client-side rate limiting, retry logic with exponential backoff, or handling of rate limit responses. While GitHub enforces server-side limits, the script could make rapid successive requests that exhaust the user's quota or cause availability issues.
