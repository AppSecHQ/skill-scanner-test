This skill package has MEDIUM security concerns primarily due to deceptive presentation. The skill masquerades as an agent skill but actually provides documentation for an external npm package (ai-lighthouse) without including any executable scripts. This creates a significant mismatch between user expectations and actual functionality. The skill is not inherently malicious - it does not attempt data exfiltration, prompt injection, or credential theft. However, the lack of actual implementation code combined with instructions to run external tools (npx) creates ambiguity about what the agent would actually execute. The missing manifest metadata (license, compatibility, allowed-tools) and embedded promotional content are minor issues. If this skill were to include actual scripts that execute 'npx ai-lighthouse', additional security analysis would be needed to assess the risks of running external npm packages.

Findings

MEDIUM Deceptive Skill Description - External Tool Masquerading as Agent Skill Social Engineeringllm

The skill description and instructions describe an external npm package (npx ai-lighthouse) rather than an actual agent skill with executable code. The SKILL.md contains only documentation for running an external tool via 'npx ai-lighthouse', with no Python/Bash scripts provided. This creates a mismatch between what users expect (an agent skill that performs audits) and what is delivered (instructions to run an external npm package). Users may be misled into thinking this is a self-contained skill when it actually requires external package execution.

SKILL.md

Quick Start section shows: 'npx ai-lighthouse https://mysite.com' - This is an external npm package call, not agent skill functionality. No Python/Bash scripts are included to implement the described functionality.
Remediation: Either: (1) Include actual Python/Bash scripts that implement the Lighthouse audit functionality within the skill package, or (2) Clearly document in the description that this skill provides instructions for using an external npm tool rather than being a self-contained agent skill. Update the description to: 'Instructions for running the ai-lighthouse npm package to perform performance audits' to set accurate expectations.

What we checked

  • Static analyzer. Pattern rules over SKILL.md and bundled files: known-bad commands, exfiltration URLs, secrets, obfuscation.
  • Behavioral analyzer. Checks what the skill asks the agent to do against what its description claims it does.
  • Llm analyzer. A language model reads the skill and reports intent-level issues the rules cannot express.
  • Trigger analyzer. Looks for instructions that fire on conditions the user did not ask for.
  • Meta analyzer. A second model pass that validates, deduplicates and re-scores the other analyzers' findings.

What we did not check

  • Runtime behaviour. The skill was not executed; findings come from reading its files.
  • Anything fetched at install or run time, including remote scripts, package dependencies, and URLs the skill tells the agent to open.
  • Content the analyzers cannot read: images, binaries, and some non-English text.
  • Known scanner bypass classes. See the methodology and limitations page.
