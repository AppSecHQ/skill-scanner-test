What this skill does

Uses the Biohub esm Python SDK for ESM3 protein generation, ESMC embeddings, and ESMFold2 all-atom folding. Applies to local model inference and Biohub hosted clients, including former Forge workflows; distinguishes the separate legacy fair-esm distribution.

Compatibility
Requires Python 3.12+ and esm 3.4.1.post1. Local pretrained inference needs model weights and sufficient RAM or GPU memory; hosted inference needs network access and ESM_API_KEY. Use an isolated environment, separate from fair-esm.

SKILL.md covers: ESM: protein generation, embeddings, and folding · When to use · Setup and model choice · Workflow · ESM3 completion and fresh structure prediction · A fresh sequence-only prompt prevents old coordinates conditioning the check. · ESMC embeddings with correct residue pooling · Hosted authentication and folding · Scientific checks · Verification and sources · Citing Scientific Agent Skills
