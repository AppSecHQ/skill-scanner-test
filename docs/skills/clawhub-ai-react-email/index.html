The react-email skill presents MEDIUM security risks primarily related to command execution safety and prompt injection. The skill requires executing arbitrary shell commands to scaffold projects and install dependencies from npm, which introduces supply chain risks. The 'EXECUTE NOW' directive in the instructions attempts direct prompt injection to force immediate execution without user confirmation. The skill also starts an unbounded development server without lifecycle management guidance. However, the skill's core functionality (creating email templates with React) is legitimate, and the referenced files contain standard documentation without malicious content. The internal reference files (COMPONENTS.md, PATTERNS.md, I18N.md, SENDING.md) are normal skill resources and not security threats. Missing optional metadata (allowed-tools, compatibility) reduces transparency but is not a critical issue. With proper safeguards around command execution and removal of imperative directives, this skill could be used safely.

Findings

MEDIUM Command Injection Risk via Unvalidated Package Manager Execution Command Injectionllm

The skill instructs the agent to execute arbitrary shell commands (npx, yarn, pnpm, bun) to scaffold a new project and install dependencies without any validation or sandboxing. The commands use 'create-email@latest' which fetches and executes code from npm registry at runtime. An attacker could potentially compromise the npm package or perform typosquatting attacks. Additionally, the 'EXECUTE NOW' directive attempts to force immediate execution without user confirmation.

SKILL.md

npx create-email@latest
yarn create email
pnpm create email
bun create email

EXECUTE NOW: Complete the above TODO list to achieve: The React Email development server is running and accessible at localhost:3000, displaying email template previews.
Remediation: 1. Remove the 'EXECUTE NOW' directive that bypasses user confirmation. 2. Add explicit warnings about executing third-party code. 3. Recommend verifying package integrity before installation. 4. Suggest pinning to specific versions instead of '@latest'. 5. Implement user confirmation before executing any shell commands.
MEDIUM Direct Prompt Injection via 'EXECUTE NOW' Command Prompt Injectionllm

The SKILL.md instructions contain a direct prompt injection attempt using 'EXECUTE NOW: Complete the above TODO list' which tries to force the agent to immediately execute commands without user oversight. This directive attempts to override the agent's normal confirmation and safety mechanisms by issuing imperative commands.

SKILL.md:58

EXECUTE NOW: Complete the above TODO list to achieve: The React Email development server is running and accessible at localhost:3000, displaying email template previews.
Remediation: Remove all 'EXECUTE NOW' or similar imperative directives from skill instructions. Replace with conditional language like 'If the user requests, you may...' or 'When appropriate, consider...'. Ensure all actions require explicit user confirmation.
