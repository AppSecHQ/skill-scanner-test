Findings

HIGH API Key Exposure Risk via Instruction to Store Credentials in Plaintext Data Exfiltrationllm

The skill instructs users to save API keys in plaintext files (~/.config/clawmail/credentials.json) and mentions storing them in 'memory, environment variables, or wherever you store secrets'. This creates a significant credential exposure risk, especially for autonomous agents that may not implement secure credential storage. The API key is described as 'your identity' and grants full access to the agent's email account.

SKILL.md

Recommended:** Save your credentials to `~/.config/clawmail/credentials.json`:

```json
{
  "api_key": "cmail_xxx",
  "agent_id": "my-agent",
  "email": "my-agent@clawmail.to"
}
```

This way you can always find your key later. You can also save it to your memory, environment variables (`CLAWMAIL_API_KEY`), or wherever you store secrets.
Remediation: Recommend secure credential storage mechanisms (OS keychain, encrypted vaults, secure environment variable management). Warn against plaintext storage. Provide guidance on proper secret management for autonomous agents.
MEDIUM External Dependency on Remote Skill Files Without Integrity Verification Unauthorized Tool Usellm

The skill instructions reference external files (skill.md, skill.json) hosted at clawmail.to URLs and encourage users to 'just read them from the URLs above' or 'Re-fetch these files anytime to see new features'. This creates a supply chain risk where the skill behavior could be modified remotely without user awareness or integrity verification (no checksums, signatures, or version pinning).
