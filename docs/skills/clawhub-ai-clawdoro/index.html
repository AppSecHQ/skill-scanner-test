ClawDoro is a Pomodoro timer skill with MEDIUM security concerns. The primary risks are: (1) starting an HTTP server on a hardcoded port without user confirmation, creating network exposure, and (2) executing Node.js code (trigger.js) that is not provided for security review, creating a transparency gap. The skill appears to be a legitimate productivity tool, but the missing source code for trigger.js prevents full security validation. The network server component introduces attack surface that should be minimized through localhost-only binding and ephemeral ports. Minor issues include missing metadata (allowed-tools, license, compatibility) and lack of server lifecycle documentation. Recommend requiring full source code disclosure and implementing network security controls before deployment.

Findings

MEDIUM Hardcoded Network Port Exposure Data Exfiltrationllm

The skill starts an HTTP server on a hardcoded port 8765 without user confirmation or security controls. This creates a network-accessible endpoint on the user's machine that could be exploited by malicious websites or local attackers to interact with the timer interface or potentially probe for vulnerabilities.

SKILL.md:29

Opens a mini HTTP server on port 8765
Remediation: Use a randomly assigned ephemeral port instead of a hardcoded port. Bind only to localhost (127.0.0.1) explicitly. Add user confirmation before starting the server. Implement proper server shutdown mechanisms.
MEDIUM Arbitrary JavaScript Execution via Node.js Command Injectionllm

The skill executes Node.js scripts (trigger.js) which are not provided for security review. The commands configuration shows direct execution of JavaScript files without visibility into what code is actually running. This creates a blind spot where malicious code could perform unauthorized operations including file system access, network requests, or system commands.

Remediation: Include trigger.js in the skill package for security review. Implement code signing or integrity checks. Restrict Node.js capabilities using --no-network or similar flags. Provide full source code transparency.
