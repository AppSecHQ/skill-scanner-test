What this skill does

Run a real-time AI phone agent using Twilio, Deepgram, and ElevenLabs. Handles incoming calls, transcribes audio, generates responses via LLM, and speaks back via streaming TTS. Use when user wants to: (1) Test voice AI capabilities, (2) Handle phone calls programmatically, (3) Build a conversational voice bot.

Findings

CRITICAL Hardcoded API Keys and Credentials in Source Code Data Exfiltrationllm

The server.py script contains hardcoded Twilio phone number (+18665515246) and references to API keys that may be committed to version control. While environment variables are used for most credentials, the presence of hardcoded values and the pattern of credential handling creates risk of accidental exposure. The script also accesses multiple sensitive API keys (Deepgram, OpenAI, ElevenLabs, Brave, Twilio) which if logged or exposed could lead to unauthorized access.

scripts/server.py

TWILIO_PHONE_NUMBER = os.getenv("TWILIO_PHONE_NUMBER", "+18665515246")
Remediation: Remove all hardcoded credentials and phone numbers. Use environment variables exclusively without defaults. Implement secrets management solution. Add .env to .gitignore. Audit all logging statements to ensure credentials are never logged.
HIGH Command Injection Risk via Shebang with Hardcoded Virtual Environment Path Command Injectionllm

Both Python scripts use hardcoded shebang paths (#!/home/art/.local/venvs/phone-agent/bin/python3) that reference a specific user's home directory. This creates a security risk if the skill is distributed and executed on different systems, as it could execute arbitrary Python interpreters. The hardcoded path also reveals internal system structure and username information.

scripts/server.py

#!/home/art/.local/venvs/phone-agent/bin/python3
Remediation: Replace hardcoded shebang with portable version: #!/usr/bin/env python3. This allows the system to use the appropriate Python interpreter from PATH. Document virtual environment setup separately in README without hardcoding paths.
HIGH Unbounded Resource Consumption via WebSocket Connections Resource Abusellm

The server accepts unlimited WebSocket connections without rate limiting, connection limits, or timeout controls. The audio streaming loops run indefinitely without bounds checking. This creates risk of resource exhaustion and denial of service attacks. The server also lacks proper error handling for connection failures, which could lead to resource leaks.

scripts/server.py

while True loops in handle_twilio_stream and handle_openai_stream without timeout or connection limits, no maximum connection count enforced
Remediation: Implement connection limits (max concurrent connections). Add timeouts for idle connections. Implement rate limiting per IP/phone number. Add circuit breakers for external API failures. Implement proper cleanup in exception handlers. Add monitoring for resource usage.
MEDIUM Missing allowed-tools Declaration Creates Ambiguity Unauthorized Tool Usellm

The skill manifest does not declare allowed-tools, making it unclear what agent capabilities are required or authorized. The skill requires network access, file system access (for .env files), and process execution (running FastAPI server), but these requirements are not explicitly declared. This creates ambiguity about the skill's intended permissions and makes it harder for users to assess risk.

SKILL.md

allowed-tools: Not specified
Remediation: Add explicit allowed-tools declaration: [Bash, Python, Read]. Document that the skill requires network access and will start a local server. Add compatibility field specifying environment requirements (Linux/Mac, Python 3.8+, network access).
MEDIUM Incomplete Disclosure of External Dependencies and Data Flows Social Engineeringllm

The skill description mentions Twilio, Deepgram, and ElevenLabs but does not disclose that it also uses Brave Search API and makes additional network calls. The description does not clearly warn users that their voice data, transcripts, and conversation content will be sent to multiple third-party services. This creates a social engineering risk where users may not fully understand the data sharing implications.

SKILL.md

Description mentions 3 services but code uses 5+ external APIs (Twilio, Deepgram, OpenAI, ElevenLabs, Brave Search). No clear warning about data sharing with third parties.
Remediation: Update description to list ALL external services used. Add explicit privacy warning about data sharing. Document data retention policies of third-party services. Provide opt-out mechanisms for optional features (like web search).
