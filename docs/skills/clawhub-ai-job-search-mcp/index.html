Job Search MCP

SAFE max severity MEDIUM registry clawhub.ai last scanned 2026-02-06 1 scan

Verdict safe, but 2 findings (2 medium), mainly data exfiltration. Most recent scan 2026-02-06.

The Job Search MCP skill is a relatively safe wrapper around the JobSpy MCP server with LOW to MEDIUM severity issues. The skill itself contains no malicious code, prompt injection attempts, or data exfiltration logic. The primary concerns are: (1) missing optional metadata fields that would improve transparency, (2) incomplete documentation, (3) supply chain risks from unpinned dependencies and unverified external repository clones. The skill functions as a documentation/configuration guide rather than executable code, which limits its attack surface. The main risks are indirect - users could install compromised versions of dependencies or clone a malicious repository if the external sources are compromised. No direct security threats (prompt injection, credential theft, command injection) were detected in the skill content itself.

Findings

MEDIUM External Dependency Installation Without Version Pinning Data Exfiltrationllm

The installation instructions recommend installing dependencies without pinned versions (e.g., 'mcp>=1.1.0', 'python-jobspy>=1.1.82'). This creates supply chain risk as future versions could introduce malicious code or breaking changes.

SKILL.md

pip install mcp>=1.1.0 python-jobspy>=1.1.82 pandas>=2.1.0 pydantic>=2.0.0
Remediation: Pin exact versions for all dependencies to ensure reproducible and secure installations. Example: 'pip install mcp==1.1.0 python-jobspy==1.1.82 pandas==2.1.0 pydantic==2.0.0'. Document the tested versions explicitly.
MEDIUM Unverified External Repository Clone Data Exfiltrationllm

The skill instructs users to clone an external GitHub repository (github.com/chinpeerapat/jobspy-mcp-server) without providing verification mechanisms (commit hash, GPG signature, checksum). This creates supply chain risk as the repository could be compromised or modified after publication.

SKILL.md

git clone https://github.com/chinpeerapat/jobspy-mcp-server.git
Remediation: Provide a specific commit hash or tag to clone (e.g., 'git clone --branch v1.0.0'), include checksums for verification, or recommend users verify the repository's authenticity before installation. Document the trusted commit hash in the skill manifest.

What we checked

  • Static analyzer. Pattern rules over SKILL.md and bundled files: known-bad commands, exfiltration URLs, secrets, obfuscation.
  • Behavioral analyzer. Checks what the skill asks the agent to do against what its description claims it does.
  • Llm analyzer. A language model reads the skill and reports intent-level issues the rules cannot express.
  • Trigger analyzer. Looks for instructions that fire on conditions the user did not ask for.
  • Meta analyzer. A second model pass that validates, deduplicates and re-scores the other analyzers' findings.

What we did not check

  • Runtime behaviour. The skill was not executed; findings come from reading its files.
  • Anything fetched at install or run time, including remote scripts, package dependencies, and URLs the skill tells the agent to open.
  • Content the analyzers cannot read: images, binaries, and some non-English text.
  • Known scanner bypass classes. See the methodology and limitations page.
