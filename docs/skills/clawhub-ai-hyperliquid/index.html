This skill presents CRITICAL security risks due to its requirement for users to provide private keys that control real financial assets. The skill installs and executes an unverified third-party binary (hyperliquid-cli) with full access to trading credentials, creating significant potential for fund loss through bugs, malicious updates, or supply chain attacks. While the skill may provide legitimate trading functionality, the security architecture is fundamentally flawed for handling financial credentials. Users should exercise extreme caution and only use this skill with test accounts or minimal funds until security improvements are implemented.

Findings

CRITICAL Hardcoded Private Key Requirement with Direct Trading Access Data Exfiltrationllm

The skill requires users to provide their HYPERLIQUID_PRIVATE_KEY as an environment variable, which grants full trading authority over the user's Hyperliquid account. This private key enables unlimited fund transfers, trades, and account control. The skill executes a third-party binary ('hl') that has direct access to this critical credential, creating significant risk of fund loss through bugs, malicious updates, or compromised dependencies.

SKILL.md

requires: {env: ['HYPERLIQUID_PRIVATE_KEY']}

Instructions state: 'Export the private key (starts with 0x)' and 'export HYPERLIQUID_PRIVATE_KEY=0x...your_private_key...'
Remediation: 1. Implement read-only mode by default that doesn't require private keys. 2. Use hardware wallet integration or signing services instead of raw private keys. 3. Implement transaction approval workflows requiring explicit user confirmation. 4. Add spending limits and risk controls. 5. Warn users about the risks of exposing private keys to third-party binaries.
HIGH Unverified Third-Party Binary Execution with Financial Authority Unauthorized Tool Usellm

The skill installs and executes 'hyperliquid-cli' via npm, a third-party binary with full access to the user's trading private key. There is no verification of the binary's integrity, no pinned version specified, and no security audit mentioned. The binary runs with complete authority to execute trades, transfer funds, and manage positions. Users have no visibility into what the binary actually does with their credentials.

SKILL.md

install: ['npm install -g hyperliquid-cli']

No version pinning (e.g., hyperliquid-cli@1.2.3)
No integrity checks or signature verification
Binary has full access to HYPERLIQUID_PRIVATE_KEY
Remediation: 1. Pin specific versions with integrity hashes (npm install -g hyperliquid-cli@x.y.z --integrity sha512-...). 2. Provide security audit information or source code review. 3. Implement sandboxing or permission boundaries. 4. Add warnings about third-party binary risks. 5. Consider implementing the trading logic directly in auditable Python/Bash scripts instead of relying on external binaries.
HIGH Persistent Background Server with Unbounded Resource Consumption Resource Abusellm

The skill starts a persistent background server ('hl server start') that maintains WebSocket connections and in-memory caching indefinitely. There are no documented resource limits, timeout configurations, or automatic cleanup mechanisms. The server could consume excessive memory/CPU, create zombie processes, or maintain stale connections. Users may forget to stop the server, leading to resource leaks.

SKILL.md

Instructions: 'hl server start' with 'Persistent WebSocket connections' and 'In-memory caching'

No timeout limits mentioned
No automatic cleanup or resource bounds
No monitoring of resource consumption
Remediation: 1. Implement automatic server shutdown after inactivity periods. 2. Add resource limits (max memory, max connections). 3. Implement health checks and automatic restart on failure. 4. Add monitoring commands to check resource usage. 5. Warn users to stop the server when done. 6. Implement automatic cleanup of stale connections.

What we checked

  • Static analyzer. Pattern rules over SKILL.md and bundled files: known-bad commands, exfiltration URLs, secrets, obfuscation.
  • Behavioral analyzer. Checks what the skill asks the agent to do against what its description claims it does.
  • Llm analyzer. A language model reads the skill and reports intent-level issues the rules cannot express.
