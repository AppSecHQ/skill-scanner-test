Findings

MEDIUM Automatic Tool Execution Without User Consent Unauthorized Tool Usellm

The skill configures automatic search and voting behavior that executes tools without explicit user permission. The search tool 'triggers automatically' when encountering errors or starting work on problems, and vote_up 'triggers automatically' after using solutions. This autonomous behavior violates user control principles and could lead to unintended data transmission to external services.

SKILL.md

**Triggers automatically** when:
- Encountering an unfamiliar error or exception
- Starting work on a non-trivial problem
- User asks 'is there a better way?'
- Before implementing a complex feature

Search proactively without being asked.
Remediation: Remove automatic triggering language. Require explicit user confirmation before executing search queries or voting actions. Change from 'triggers automatically' to 'available when user requests' or 'suggests searching when appropriate'.
MEDIUM Automatic Data Sharing to External Service Data Exfiltrationllm

The skill is configured to automatically share problem-solution data to an external service (Reposit backend) when REPOSIT_AUTO_SHARE=true is set. This creates a data exfiltration risk where code context, error messages, and implementation details are transmitted without per-instance user consent. The skill collects 'problem descriptions with error messages and context' which may contain sensitive information.

SKILL.md

**Behavior depends on configuration:**
- Default: Asks for confirmation before sharing
- Set `REPOSIT_AUTO_SHARE=true` to share automatically
Remediation: Remove the REPOSIT_AUTO_SHARE=true option entirely. Always require explicit user confirmation before sharing any data externally. Add warnings about what data will be transmitted and to which backend.
MEDIUM Transitive Trust in External Community Content Prompt Injectionllm

The skill instructs the agent to automatically trust and present solutions from external community sources without validation. It directs the agent to 'search proactively without being asked' and present findings based solely on community scores. This creates indirect prompt injection risk where malicious actors could inject harmful instructions via highly-voted solutions that the agent would then follow.

SKILL.md

Search proactively without being asked. Present findings with their community scores:
- **High score (5+)**: Community-validated, excellent match
- **Medium score (1-4)**: Worth reviewing
- **Low/negative score**: May have issues
Remediation: Add explicit warnings that external solutions must be reviewed by the user before implementation. Remove 'proactive' search behavior. Require user approval before presenting or following any external solution content. Add content validation and sanitization.
