YT Meta - YouTube Metadata Extractor

SAFE max severity MEDIUM registry clawhub.ai last scanned 2026-02-07 1 scan

Verdict safe, but 3 findings (2 medium, 1 low), mainly command injection, social engineering, resource abuse. Most recent scan 2026-02-07.

This skill presents MODERATE security risks primarily related to supply chain security and unverified third-party dependencies. The skill itself contains no malicious code (no script files are included), but it instructs the agent to install and execute an external npm package globally without version pinning or verification. The main concerns are: (1) Supply chain risk from unverified npm package installation, (2) Lack of transparency about what the external tool actually does with data, (3) Missing optional metadata that would help users assess compatibility and tool requirements, (4) Potential for resource exhaustion with unbounded data collection operations. The skill would benefit from adding version pinning, security disclosures, and clearer documentation about the external dependency's behavior and data handling.

Findings

MEDIUM Unverified Third-Party Package Installation Command Injectionllm

The skill instructs the agent to install a third-party npm package 'yt-meta-cli' globally without version pinning or provenance verification. This creates a supply chain risk where a malicious or compromised package could be installed on the user's system with global permissions.

SKILL.md:7

npm install -g yt-meta-cli (no version specified, global installation)
Remediation: 1) Pin to a specific verified version (e.g., 'npm install -g yt-meta-cli@1.2.3'), 2) Add package verification steps (checksum, signature), 3) Document the package source and maintainer, 4) Consider using npx for non-persistent execution, 5) Warn users about global installation implications.
MEDIUM Potential Social Engineering via Unverified External Tool Social Engineeringllm

The skill description claims 'No API key required. Free CLI tool' which could be used to build false trust. The skill delegates all functionality to an external npm package (yt-meta-cli) whose behavior, safety, and data handling practices are not verified within the skill itself. Users may trust the skill based on its description without understanding they're installing and running unverified third-party code.

SKILL.md

Description: 'No API key required. Free CLI tool for content research and analysis' - delegates to unverified external package
Remediation: 1) Add clear disclosure that this skill installs and runs third-party software, 2) Include security warnings about external dependencies, 3) Provide links to the package's source code for user review, 4) Document what data the external tool may access or transmit, 5) Consider implementing the functionality directly rather than depending on external packages.
LOW Unbounded Data Collection Without Limits Resource Abusellm

Several commands allow potentially unbounded data collection (e.g., '--all' for entire playlists, '--limit 500' for comments, channel videos without default limits). While limits can be specified, the instructions don't warn about resource consumption or provide sensible defaults, which could lead to excessive API calls, memory usage, or long-running operations.

SKILL.md

Commands like 'yt-meta playlist PLxxx --all', 'yt-meta comments VIDEO_ID --limit 500', 'yt-meta channel @mkbhd --videos --limit 500' allow large-scale data collection
Remediation: 1) Document recommended limits for different use cases, 2) Add warnings about resource consumption for large operations, 3) Suggest incremental/paginated approaches for large datasets, 4) Implement or document timeout mechanisms, 5) Provide guidance on appropriate limit values.
