This trading analysis skill presents MEDIUM security risks primarily related to supply chain security and sensitive data handling. The skill requires users to clone an external GitHub repository and install unpinned dependencies without verification mechanisms, creating supply chain vulnerabilities. Additionally, it processes highly sensitive financial trading data (broker CSV exports containing transaction history and P&L information) without providing security guidance on data privacy and handling. The skill itself does not contain malicious code in the provided materials - no scripts were included for analysis, only documentation. However, the installation process and data handling practices need security improvements. The missing optional metadata fields (license, compatibility, allowed-tools) reduce transparency but are low severity issues. Overall, this appears to be a legitimate trading analysis tool with supply chain and data privacy concerns that should be addressed.

MEDIUM Hardcoded External Repository Clone Without Verification Data Exfiltrationllm

The installation instructions direct users to clone a GitHub repository (https://github.com/BENZEMA216/tradingcoach.git) without any integrity verification, version pinning, or provenance checking. This creates a supply chain risk where malicious code could be introduced through repository compromise or typosquatting.

SKILL.md

git clone https://github.com/BENZEMA216/tradingcoach.git ~/tradingcoach
Remediation: Add commit hash verification, use signed releases, or include integrity checksums. Document the expected repository state and warn users to verify the source.
MEDIUM Unpinned Dependency Installation Data Exfiltrationllm

The skill instructs users to run 'pip install -r requirements.txt' without specifying or documenting pinned versions. This creates supply chain vulnerability where malicious or compromised package versions could be installed.

SKILL.md

pip install -r requirements.txt
Remediation: Pin all dependencies to specific versions in requirements.txt. Use hash verification (pip install --require-hashes). Document expected package versions.
MEDIUM Sensitive Financial Data Processing Without Security Guidance Data Exfiltrationllm

The skill processes sensitive financial trading data (CSV files containing transaction history, account positions, P&L data) but provides no security guidance on data handling, storage, or privacy. Users may inadvertently expose sensitive financial information.

SKILL.md

将券商导出的CSV交易记录,转化为专业级复盘报告 - processes broker CSV exports containing sensitive trading data
Remediation: Add explicit security warnings about: (1) Not sharing CSV files containing real trading data, (2) Data retention policies, (3) Secure deletion after analysis, (4) Privacy considerations when using AI analysis features.
