Findings

HIGH Hardcoded Credentials in User Home Directory Data Exfiltrationllm

The skill requires users to store Habitica API credentials (USER_ID and API_TOKEN) in plaintext in ~/.habitica file. While this is a common pattern for CLI tools, it creates a credential exposure risk if the skill or other malicious skills gain read access to this file. The credentials provide full account access to the user's Habitica account.

SKILL.md

Credentials in `~/.habitica`:
```bash
HABITICA_USER_ID="your-user-id"
HABITICA_API_TOKEN="your-api-token"
```
Remediation: 1. Document the security implications of storing credentials in plaintext. 2. Consider using system keychain/credential managers where available. 3. Ensure file permissions are restrictive (chmod 600 ~/.habitica). 4. Warn users that other skills with Read access can potentially access these credentials.
MEDIUM Network Data Transmission to Third-Party API Data Exfiltrationllm

The skill makes authenticated API calls to habitica.com (https://habitica.com/api/v3) with user credentials. While this is the legitimate Habitica API and expected behavior for this integration, users should be aware that task data, user stats, and other personal information is transmitted to external servers. The skill description does not explicitly warn users about network usage.

scripts/habitica.sh:8

BASE_URL="https://habitica.com/api/v3"
Remediation: 1. Add explicit disclosure in the skill description that this skill makes network calls to Habitica's servers. 2. Add 'compatibility' field noting network requirement. 3. Consider adding a warning in SKILL.md about data transmission.
