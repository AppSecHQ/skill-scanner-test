The hugging-face-evaluation skill is a legitimate tool for managing model evaluation results with MEDIUM security risk. The skill provides useful functionality for extracting evaluation tables and importing benchmark scores, but has several security concerns: (1) API key handling in example scripts could expose credentials, (2) subprocess command construction lacks input sanitization creating command injection risks, (3) markdown parsing lacks resource limits for DoS protection, (4) missing manifest metadata reduces transparency. The skill does NOT contain malicious code, data exfiltration, or prompt injection attempts. The primary risks are defensive coding issues rather than intentional threats. The scripts appropriately use HuggingFace's official APIs and follow standard patterns for evaluation workflows.

What this skill does

Add and manage evaluation results in Hugging Face model cards. Supports extracting eval tables from README content, importing scores from Artificial Analysis API, and running custom model evaluations with vLLM/lighteval. Works with the model-index metadata format.
