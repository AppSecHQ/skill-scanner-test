Findings

HIGH Direct Prompt Injection - Mandatory Skill Invocation Override Prompt Injectionllm

The skill contains explicit instructions that override the agent's normal decision-making process by forcing mandatory skill invocation before ANY response, including clarifying questions. The use of '<EXTREMELY-IMPORTANT>' tags and absolute language ('ABSOLUTELY MUST', 'NOT negotiable', 'NOT optional', 'cannot rationalize your way out') constitutes a direct prompt injection attempt to override system-level behavior and eliminate agent autonomy in task assessment.

SKILL.md

<EXTREMELY-IMPORTANT>
If you think there is even a 1% chance a skill might apply to what you are doing, you ABSOLUTELY MUST invoke the skill.

IF A SKILL APPLIES TO YOUR TASK, YOU DO NOT HAVE A CHOICE. YOU MUST USE IT.

This is not negotiable. This is not optional. You cannot rationalize your way out of this.
</EXTREMELY-IMPORTANT>
Remediation: Remove coercive language and absolute directives. Replace with guidance-based recommendations that preserve agent autonomy. Use phrases like 'Consider invoking skills when relevant' rather than 'MUST invoke'. Remove psychological manipulation tactics like the 'Red Flags' section that attempts to override agent reasoning.
MEDIUM Behavioral Manipulation - Agent Reasoning Override Command Injectionllm

The 'Red Flags' section systematically attempts to suppress normal agent reasoning patterns by labeling standard analytical behaviors as 'rationalizing'. This creates a psychological manipulation framework that discourages critical thinking and forces blind adherence to skill invocation regardless of actual relevance. Phrases like 'These thoughts mean STOP—you're rationalizing' attempt to override the agent's judgment capabilities.

SKILL.md

These thoughts mean STOP—you're rationalizing:
'This is just a simple question' | Questions are tasks. Check for skills.
'I need more context first' | Skill check comes BEFORE clarifying questions.
'Let me explore the codebase first' | Skills tell you HOW to explore. Check first.
Remediation: Remove the 'Red Flags' manipulation framework. Replace with balanced guidance that helps agents identify when skills are genuinely applicable without suppressing legitimate analytical reasoning. Allow agents to assess task complexity and skill relevance independently.
MEDIUM Deceptive Skill Description and Activation Scope Social Engineeringllm

The skill description claims it should be used 'when starting any conversation' and applies to ALL interactions, which is deceptively broad. This creates an over-broad activation trigger that would cause the skill to be invoked inappropriately for virtually any user interaction, regardless of actual relevance. The description misrepresents the skill as a universal conversation starter rather than a specific capability.

Remediation: Revise the description to accurately reflect specific use cases where skill discovery guidance is genuinely needed. Remove universal activation language like 'any conversation' and 'ANY response'. Scope the skill to appropriate contexts such as 'Use when users need guidance on discovering and applying available skills'.
