The instruction body contains code examples with placeholder connection strings and endpoints that users might accidentally use with real credentials. While these are examples, they demonstrate patterns where sensitive credentials could be hardcoded directly in code.

SKILL.md

CallAutomationClient client = new CallAutomationClientBuilder()

    .buildClient();
Remediation: Add explicit warnings in the instructions about never hardcoding real credentials. Recommend using environment variables or Azure Key Vault for credential management. Include example: System.getenv("AZURE_CONNECTION_STRING")
