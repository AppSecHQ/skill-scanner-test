This skill presents MODERATE TO HIGH security risks primarily related to financial operations and credential management. The skill enables autonomous real-money trading on prediction markets (Polymarket) with USDC cryptocurrency, involving API keys that control wallets with spending limits ($100/trade, $500/day). Key concerns include: (1) plaintext credential storage in user files, (2) social engineering messaging to persuade users to enable real money trading, (3) autonomous financial transactions without per-trade user confirmation, and (4) missing referenced implementation files that prevent full security analysis. While the skill includes some safety features (spending limits, managed wallets), the combination of financial access, credential exposure, and autonomous operation creates significant risk. The skill would benefit from secure credential management, mandatory per-trade user approval, and complete transparency of all implementation code.

HIGH Hardcoded API Key Storage in User Credentials File Data Exfiltrationllm

The skill instructs the agent to store API keys in plaintext in ~/.config/simmer/credentials.json or as environment variables. This creates a persistent credential that could be accessed by other processes or exfiltrated. The skill involves financial trading with real money (USDC) and the API key controls a wallet with spending limits ($100/trade, $500/day). If compromised, an attacker could drain funds up to the daily limit.

SKILL.md

# Option 1: Save to credentials file (recommended)
mkdir -p ~/.config/simmer
echo '{"api_key": "sk_live_..."}' > ~/.config/simmer/credentials.json

# Option 2: Environment variable
export SIMMER_API_KEY="sk_live_..."
Remediation: Implement secure credential storage using system keychains (macOS Keychain, Windows Credential Manager, Linux Secret Service). Use temporary session tokens instead of long-lived API keys. Require explicit user consent before storing credentials. Consider using OAuth flows instead of API keys for agent authentication.
