The multi-llm skill is a LOCAL MODEL SWITCHING utility that intelligently routes tasks to different Ollama models based on task type detection. The skill is SAFE with minor documentation improvements needed. It does NOT exhibit malicious behavior - no data exfiltration, no prompt injection, no credential theft. The network calls are legitimate (localhost:11434 for Ollama API). The skill operates as described: defaults to Claude Opus 4.5 unless 'multi llm' trigger is used, then selects appropriate local models. The skill is well-structured with clear fallback chains and model availability checking.
