What this skill does

Create beautiful visual art in .png and .pdf documents using design philosophy. You should use this skill when the user asks to create a poster, piece of art, design, or other static piece. Create original visual designs, never copying existing artists' work to avoid copyright violations.

Findings

MEDIUM Transitive Trust Abuse - Instruction Following from User Input Prompt Injectionllm

The skill instructions contain a critical misunderstanding of its role. The phrase 'What is received: Some subtle input or instructions by the user that should be taken into account' followed by 'The next phase involves making the artwork' suggests the skill may follow instructions embedded in user input rather than treating user input as data to be processed. This creates a transitive trust vulnerability where malicious instructions in user requests could be executed as commands rather than treated as content to design around.

SKILL.md

'What is received: Some subtle input or instructions by the user that should be taken into account, but used as a foundation; it should not constrain creative freedom.' and 'The next phase involves making the artwork' - This framing suggests following user instructions rather than treating them as design requirements.
Remediation: Reframe instructions to clearly distinguish between: (1) User design requirements (data to process), and (2) Skill operational instructions (commands to follow). Use language like 'User provides design requirements' rather than 'instructions by the user' to avoid confusion about what should be executed vs. what should be designed.
MEDIUM Incomplete Manifest - Missing Critical Security Fields Social Engineeringllm

The skill manifest is missing critical security-relevant fields: 'compatibility' and 'allowed-tools' are both 'Not specified'. While allowed-tools is optional per spec, its absence prevents users and systems from understanding what capabilities this skill requires. The skill creates .md, .pdf, and .png files, which implies Write tool usage at minimum, but this is not declared. Missing compatibility information prevents users from understanding execution environment requirements.

SKILL.md

compatibility: Not specified, allowed-tools: Not specified. Instructions state: 'Output only .md files, .pdf files, and .png files' which implies Write tool requirement.
Remediation: Add 'allowed-tools: [Write]' to manifest to declare file creation capabilities. Add 'compatibility' field specifying supported environments (Claude.ai, Claude Code, API). This improves transparency and allows security validation of tool usage.
