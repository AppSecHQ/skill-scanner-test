Findings

MEDIUM Hardcoded API Key Requirement Without Secure Storage Guidance Data Exfiltrationllm

The skill requires MACHFIVE_API_KEY environment variable but provides no guidance on secure storage, rotation, or scope limitations. Users may hardcode keys in shell profiles or insecure locations. The skill also accepts API keys via X-API-Key header, increasing exposure surface.

Setup instructions: 'Set `MACHFIVE_API_KEY` in your environment' and 'Or use `X-API-Key: {MACHFIVE_API_KEY}` header' without security warnings or best practices.
Remediation: Add security guidance: (1) Use secure credential managers (e.g., 1Password, AWS Secrets Manager), (2) Never commit keys to version control, (3) Rotate keys regularly, (4) Use minimum-scope API keys, (5) Warn about X-API-Key header exposure in logs/network traffic.
MEDIUM Potential Data Exfiltration via Third-Party API Data Exfiltrationllm

The skill sends potentially sensitive lead data (names, titles, emails, LinkedIn URLs, company websites) to an external third-party service (app.machfive.io) without explicit user consent warnings or data handling disclosures. Users may unknowingly transmit PII and business intelligence to an external vendor.

POST requests to https://app.machfive.io/api/v1/campaigns/{campaign_id}/generate and /generate-batch send lead objects containing: name, title, company, email, company_website, linkedin_url. No privacy notice or data handling disclosure provided.
Remediation: Add explicit warnings: (1) Disclose that lead data is transmitted to MachFive's servers, (2) Link to MachFive's privacy policy and data handling practices, (3) Warn users about GDPR/CCPA compliance requirements, (4) Recommend obtaining consent before processing personal data, (5) Document data retention and deletion policies.
