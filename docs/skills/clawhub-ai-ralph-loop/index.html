What this skill does

Generate copy-paste bash scripts for Ralph Wiggum/AI agent loops (Codex, Claude Code, OpenCode, Goose). Use when asked for a “Ralph loop”, “Ralph Wiggum loop”, or an AI loop to plan/build code via PROMPT.md + AGENTS.md, SPECS, and IMPLEMENTATION_PLAN.md, including PLANNING vs BUILDING modes, backpressure, sandboxing, and completion conditions.

Findings

MEDIUM Encourages Dangerous Auto-Approval Flags Without Adequate Warning Unauthorized Tool Usellm

The skill explicitly instructs users to enable dangerous auto-approval flags (--full-auto for Codex, --dangerously-skip-permissions for Claude Code) that bypass security confirmations. While it asks 'explicitly', there is no prominent warning about the security implications of disabling permission checks in automated loops that execute arbitrary code.

SKILL.md

Auto‑approve flags (ask explicitly)
  - Codex: `--full-auto`
  - Claude Code: `--dangerously-skip-permissions`
Remediation: Add explicit security warnings about the risks of auto-approval flags. Recommend users review what commands will be executed before enabling these flags. Consider suggesting safer alternatives like limited approval scopes or requiring manual review for sensitive operations.
MEDIUM Unbounded Loop Execution Risk Resource Abusellm

The skill generates bash scripts that run AI coding CLIs in loops with only optional completion conditions. While max iterations are mentioned, the implementation details are incomplete (instruction body cuts off). Without proper safeguards, loops could run indefinitely consuming resources, especially if completion conditions fail or are misconfigured.

SKILL.md

The loop persists context via `PROMPT.md` + `AGENTS.md` (loaded every iteration)... Max iterations... Build the per‑iteration command [instruction cuts off]
Remediation: Ensure generated scripts include: (1) Mandatory max iteration limits with reasonable defaults, (2) Timeout mechanisms per iteration, (3) Resource monitoring and circuit breakers, (4) Clear error handling for failed completion conditions, (5) User confirmation before starting loops with high iteration counts.
