Findings

MEDIUM Misleading Description - No Implementation Provided Social Engineeringllm

The skill claims to provide 'Calendar management and scheduling' with features like 'Create events', 'Schedule meetings', 'Set reminders', and 'Calendar sync' across multiple providers (Google Calendar, Apple Calendar, Outlook Calendar). However, no script files or implementation code are provided. This is a deceptive skill that cannot perform any of its advertised functionality. Users may believe they are getting calendar integration capabilities when the skill has no actual implementation.

Description claims: 'Calendar management and scheduling. Create events, manage meetings, and sync across calendar providers.' Features listed: 'Create events, Schedule meetings, Set reminders, View availability, Recurring events, Calendar sync'. Supported Providers: 'Google Calendar, Apple Calendar, Outlook Calendar'. But: 'No script files found.'
Remediation: Either implement the advertised calendar functionality with appropriate Python/Bash scripts that integrate with calendar APIs, or update the description to accurately reflect that this is a template/placeholder skill with no current implementation. If this is intentionally a stub, clearly mark it as such in the description.

What we checked

  • Static analyzer. Pattern rules over SKILL.md and bundled files: known-bad commands, exfiltration URLs, secrets, obfuscation.
  • Behavioral analyzer. Checks what the skill asks the agent to do against what its description claims it does.
  • Llm analyzer. A language model reads the skill and reports intent-level issues the rules cannot express.
  • Trigger analyzer. Looks for instructions that fire on conditions the user did not ask for.
  • Meta analyzer. A second model pass that validates, deduplicates and re-scores the other analyzers' findings.

What we did not check

  • Runtime behaviour. The skill was not executed; findings come from reading its files.
  • Anything fetched at install or run time, including remote scripts, package dependencies, and URLs the skill tells the agent to open.
  • Content the analyzers cannot read: images, binaries, and some non-English text.
  • Known scanner bypass classes. See the methodology and limitations page.
