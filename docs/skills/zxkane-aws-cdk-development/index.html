Findings

MEDIUM Overly Permissive Tool Access - Unrestricted Bash Commands Unauthorized Tool Usellm

The skill declares allowed-tools with wildcard patterns that grant excessive permissions. Specifically, 'Bash(cdk *)' allows execution of ANY cdk command, 'Bash(npm *)' allows ANY npm command, 'Bash(npx *)' allows ANY npx command, and 'Bash(aws cloudformation *)' allows ANY CloudFormation command. This creates tool exploitation risks where malicious or unintended commands could be executed under the guise of legitimate CDK operations. For example, 'npm install' could install malicious packages, 'cdk destroy' could delete infrastructure, or 'aws cloudformation delete-stack' could remove critical resources.

SKILL.md

allowed-tools: mcp__cdk__*, mcp__aws-mcp__*, mcp__awsdocs__*, Bash(cdk *), Bash(npm *), Bash(npx *), Bash(aws cloudformation *), Bash(aws sts get-caller-identity)
Remediation: Restrict allowed-tools to specific, necessary commands only. Instead of wildcards, enumerate exact commands needed: ['Bash(cdk synth)', 'Bash(cdk deploy)', 'Bash(cdk diff)', 'Bash(npm install)', 'Bash(aws cloudformation describe-stacks)', 'Bash(aws sts get-caller-identity)']. Avoid patterns that allow destructive operations like 'cdk destroy', 'npm uninstall', or 'aws cloudformation delete-stack' unless explicitly required and documented.
