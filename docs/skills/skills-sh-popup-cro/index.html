Verdict safe, but 1 finding (1 medium), mainly prompt injection. Most recent scan 2026-02-07.

The popup-cro skill is a conversion rate optimization assistant focused on popup and modal design guidance. The skill appears to be primarily instructional/advisory with no executable scripts. The main security concern is MEDIUM severity: the skill instructs the agent to read and trust external content from `.claude/product-marketing-context.md` without validation, creating a transitive trust vulnerability (AITech-1.2). An attacker who controls this external file could inject malicious instructions that the agent would follow. Additionally, there is a LOW severity issue with a missing referenced file (corner.py) that could indicate incomplete packaging or potential tool shadowing risk. The skill also lacks optional metadata fields (LOW severity, informational). No data exfiltration, command injection, or direct prompt injection threats were detected. The skill's core functionality - providing CRO advice for popups - appears legitimate and matches its description.

Findings

MEDIUM Transitive Trust Abuse via External Product Marketing Context File Prompt Injectionllm

The skill instructions direct the agent to read and trust content from `.claude/product-marketing-context.md` without validation. This file is external to the skill package and could contain malicious instructions that the agent would follow. The instruction 'read it before asking questions. Use that context' creates a transitive trust relationship where untrusted external content can influence agent behavior.

SKILL.md

If `.claude/product-marketing-context.md` exists, read it before asking questions. Use that context and only ask for information not already covered or specific to this task.
Remediation: Either: (1) Bundle product-marketing-context.md within the skill package as an internal reference file, or (2) Add explicit validation that the external file contains only data/context and not instructions, or (3) Clearly document that this file should be treated as untrusted user input and sanitized before use.
