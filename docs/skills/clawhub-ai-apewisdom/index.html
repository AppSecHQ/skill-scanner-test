The apewisdom skill is a relatively straightforward Reddit sentiment scanner that fetches data from a third-party API. The primary security concern is the unvalidated trust placed in external API responses, which could be exploited if the API is compromised or returns malicious data. The skill does not attempt prompt injection, credential theft, or data exfiltration to attacker-controlled servers. However, it lacks important security metadata and proper error handling for network operations. The skill's behavior matches its stated purpose, and there are no hidden capabilities or deceptive elements. Overall risk level is MODERATE due to external API dependency without validation.

Findings

MEDIUM Unvalidated External API Data Exfiltration Risk Data Exfiltrationllm

The skill makes network requests to an external third-party API (apewisdom.io) without any validation of the response data or error handling for malicious payloads. While the API appears legitimate, the skill blindly trusts and processes external data that could contain malicious content or be compromised. The response data is directly parsed and displayed without sanitization, creating a potential vector for indirect prompt injection or data manipulation.

scripts/scan_reddit.py

response = requests.get(url)
response.raise_for_status()
data = response.json()
return data.get("results", [])[:limit]
Remediation: 1. Implement response validation to verify data structure and types before processing. 2. Add content sanitization for all string fields from the API. 3. Implement rate limiting and request timeouts. 4. Consider caching responses to reduce external dependencies. 5. Add integrity checks or use HTTPS certificate pinning for the API endpoint.
LOW Missing Request Timeout Configuration Resource Abusellm

The network requests to the external API do not specify timeout parameters, which could lead to indefinite hanging if the API becomes unresponsive. This creates a potential availability issue where the agent could become blocked waiting for a response that never arrives.

scripts/scan_reddit.py:13

response = requests.get(url)
# No timeout parameter specified
Remediation: Add timeout parameters to all network requests: ```python response = requests.get(url, timeout=10) ``` This ensures requests fail gracefully rather than hanging indefinitely.
