The azure-ai-document-intelligence-dotnet skill is a documentation-focused skill providing guidance for using Azure's Document Intelligence .NET SDK. The skill does not contain executable scripts, which significantly reduces its attack surface. However, it has MEDIUM severity security concerns related to credential management practices. The skill instructs users to store sensitive API keys and SAS tokens in environment variables without adequate security guidance, which could lead to credential exposure if users follow the examples in insecure environments. The skill also contains a misleading reference to a non-existent Python file and lacks optional metadata fields. Overall, the skill is relatively safe as it contains no executable code, but the credential handling guidance needs improvement to prevent users from inadvertently exposing sensitive credentials.

Findings

MEDIUM Hardcoded Credentials in Environment Variables Without Secure Storage Guidance Data Exfiltrationllm

The skill instructs users to store sensitive credentials (DOCUMENT_INTELLIGENCE_API_KEY) in environment variables without providing guidance on secure storage mechanisms. While environment variables are mentioned, there is no warning about the risks of exposing API keys or recommendations for using secure credential management systems (e.g., Azure Key Vault, .NET Secret Manager). This could lead users to hardcode credentials in configuration files or expose them in version control systems.

SKILL.md

```bash
DOCUMENT_INTELLIGENCE_ENDPOINT=https://<resource-name>.cognitiveservices.azure.com/
DOCUMENT_INTELLIGENCE_API_KEY=<your-api-key>
BLOB_CONTAINER_SAS_URL=https://<storage>.blob.core.windows.net/<container>?<sas-token>
```
Remediation: Add explicit warnings about credential security and recommend using Azure Key Vault or .NET Secret Manager for production environments. Include code examples showing secure credential retrieval patterns. Warn against committing credentials to version control.
LOW Missing Referenced File Creates Incomplete Documentation Social Engineeringllm

The skill instructions reference a file 'documents.py' that is not included in the skill package. This creates misleading documentation as users may expect Python examples or helper code that doesn't exist. The skill is described as a .NET SDK skill, making the Python file reference particularly confusing and potentially indicating incomplete or incorrect documentation.

Referenced file 'documents.py' not found in skill package. Skill is for .NET (C#) but references Python file.
Remediation: Remove the reference to 'documents.py' if it's not needed, or include the file if it provides valuable examples. Ensure all referenced files are included in the skill package and align with the skill's technology stack (.NET/C#).
