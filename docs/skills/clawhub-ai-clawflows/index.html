clawflows

ISSUES FOUND max severity HIGH registry clawhub.ai last scanned 2026-02-05 1 scan

5 findings (2 high, 3 medium), mainly prompt injection, unauthorized tool use, data exfiltration. Most recent scan 2026-02-05.

This skill presents MULTIPLE HIGH-SEVERITY security risks primarily related to indirect prompt injection and tool chaining abuse. The core threat is that it downloads and executes untrusted automation workflow definitions from an external registry (clawflows.com) without validation, cryptographic verification, or adequate user controls. These automations can chain multiple capabilities together (data collection → processing → transmission) enabling sophisticated attacks including data exfiltration, unauthorized tool use, and automated malicious workflows. The scheduling feature amplifies these risks by enabling persistent, automated execution. The skill lacks transparency about its trust model and does not adequately warn users that they are delegating control to external workflow definitions. While the capability-based abstraction is architecturally interesting, it creates a powerful attack surface when combined with untrusted external content. RECOMMENDATION: This skill should NOT be used in its current form without significant security enhancements including: automation signing/verification, per-step user approval, data flow restrictions, and comprehensive security warnings.

Findings

HIGH Indirect Prompt Injection via Untrusted External Automation Files Prompt Injectionllm

The skill downloads and executes automation YAML files from clawflows.com registry without validation. These files contain instructions, logic, conditions, and data flow that the agent will follow. An attacker controlling the registry or performing a supply chain attack could inject malicious instructions into automation files that the agent would execute. The 'clawflows run' command executes arbitrary workflows from external sources, creating a transitive trust vulnerability where the agent delegates trust to untrusted external content.

SKILL.md

clawflows install youtube-competitor-tracker (downloads external YAML), clawflows run youtube-competitor-tracker (executes external workflow definitions with steps, capabilities, and logic)
Remediation: Implement cryptographic signing and verification of automation files. Add content validation and sandboxing for downloaded automations. Require explicit user review and approval before executing downloaded workflows. Display automation contents and required capabilities before execution. Implement allowlisting of trusted automation sources.
HIGH Tool Chaining and Capability Abuse via Automation Workflows Unauthorized Tool Usellm

Automations can chain multiple capabilities together (youtube-data → database → chart-generation → email) creating complex multi-step workflows that execute without per-step user confirmation. The examples show data flowing between steps (capture: videos, then use ${videos}), enabling sophisticated tool chaining attacks. An attacker could create automations that: 1) collect sensitive data via one capability, 2) exfiltrate it via another (database/email), 3) perform unauthorized actions across multiple tools. The --dry-run flag suggests normal execution happens automatically without user approval of each step.

SKILL.md

Example workflow: capability: youtube-data → capture: videos → capability: database → args: data: "${videos}" (automated multi-step data flow). 'clawflows run' executes entire workflow, 'clawflows enable' sets up automated scheduling.
Remediation: Require explicit user confirmation for each capability invocation in a workflow. Implement data flow restrictions between capabilities. Add runtime monitoring and approval gates for sensitive operations. Prevent automated scheduling of workflows that access sensitive capabilities. Implement capability-based access control with user-defined policies.
MEDIUM Potential Data Exfiltration via Email and Database Capabilities Data Exfiltrationllm

The skill enables automations that can combine data collection capabilities (youtube-data, social-search, weather, calendar) with data transmission capabilities (email, database). The standard capabilities table explicitly lists 'email: Send/receive email' and 'database: Store and query data'. An attacker could create automations that collect sensitive information from various sources and automatically email it to external addresses or store it in attacker-controlled databases. The scheduling feature ('clawflows enable') could enable persistent, automated data exfiltration.

SKILL.md

Standard capabilities include: 'email: Send/receive email', 'database: Store and query data', 'social-search: Search X/Twitter', 'calendar: Read/write events'. Automations can chain these: collect data → email/database it. Scheduling enables automated execution.
Remediation: Implement strict data flow policies preventing sensitive data from reaching transmission capabilities without explicit user approval. Add audit logging for all data access and transmission operations. Require user confirmation before any email sending or external database writes. Disable automated scheduling for automations that combine collection and transmission capabilities. Implement data classification and handling policies.
MEDIUM Insufficient Transparency About External Dependencies and Trust Model Social Engineeringllm

The skill description does not clearly communicate that it downloads and executes external automation definitions from clawflows.com. Users may not understand they are trusting a third-party registry with the ability to define workflows that their agent will execute. The 'portable' nature of automations (working across any Clawbot with required capabilities) obscures the security implications of running untrusted workflow definitions. The skill presents this as a feature ('Discover and run multi-skill automations') without adequate security warnings about the trust model.

SKILL.md

Description: 'Search, install, and run multi-skill automations from clawflows.com' - no security warnings. Instructions emphasize portability and ease of use ('clawflows install', 'clawflows run') without discussing trust implications or security model.
Remediation: Add prominent security warnings in the description and instructions about the trust model. Clearly explain that automations are external code that will be executed. Implement a trust verification system (signatures, reputation scores). Add security documentation explaining risks and best practices. Require explicit user acknowledgment of risks before first use.
MEDIUM Automated Scheduling Without Resource Limits Resource Abusellm

The 'clawflows enable' command sets up automated cron-based execution of workflows without apparent resource limits or safeguards. An attacker could create automations with tight schedules that consume excessive resources, or workflows that contain infinite loops or unbounded operations. The scheduling feature combined with complex multi-step workflows creates availability disruption risks. No mention of rate limiting, execution timeouts, or resource quotas.

SKILL.md

'clawflows enable youtube-competitor-tracker # Shows cron setup instructions' - enables automated execution. No documentation of resource limits, execution timeouts, or safeguards against runaway workflows.
Remediation: Implement execution timeouts for all workflow steps. Add resource quotas (CPU, memory, network) for automated executions. Implement rate limiting for scheduled workflows. Add monitoring and automatic disabling of workflows that exceed resource thresholds. Require user approval for scheduling intervals shorter than a reasonable minimum (e.g., hourly).
