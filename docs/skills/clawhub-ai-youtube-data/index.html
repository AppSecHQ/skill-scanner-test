Findings

MEDIUM Hardcoded API Key Exposure Risk in Documentation Data Exfiltrationllm

The skill instructions demonstrate storing the API key in ~/.zshenv using a plain echo command, which could lead to accidental exposure through shell history, logs, or insecure file permissions. While this is a documentation example rather than hardcoded credentials in code, it teaches insecure credential management practices to users.

SKILL.md

Store: `echo 'export TRANSCRIPT_API_KEY="sk_..."' >> ~/.zshenv && source ~/.zshenv`
Remediation: Recommend using secure credential storage methods such as encrypted credential managers (e.g., pass, 1Password CLI, AWS Secrets Manager) or at minimum, advise users to set restrictive file permissions (chmod 600 ~/.zshenv) and warn about shell history exposure.
