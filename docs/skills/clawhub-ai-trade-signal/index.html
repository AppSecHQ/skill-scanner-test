Findings

HIGH Unvalidated External API Data Exfiltration Risk Data Exfiltrationllm

The skill sends user queries directly to an external API (https://terminal-x.ai/api) without any validation, authentication mechanism visibility, or data handling transparency. User queries may contain sensitive information about investment positions, portfolio details, or trading strategies that are transmitted to a third-party service. There is no disclosure about data retention, logging, or privacy practices of the external API.

scripts/search.sh:13

ENCODED=$(python3 -c "import urllib.parse; print(urllib.parse.quote('''$QUERY'''))")\ncurl -sL "https://terminal-x.ai/api/lite-search?query=${ENCODED}"
Remediation: 1. Add explicit user consent mechanism before sending queries to external API. 2. Implement local caching to minimize external calls. 3. Document the external API's data handling and privacy policies in SKILL.md. 4. Consider adding query sanitization to remove potentially sensitive information. 5. Implement authentication/API key mechanism with user-controlled credentials rather than anonymous calls.
MEDIUM Misleading Scope and Capability Claims Social Engineeringllm

The skill description claims to provide 'executable Buy/Sell/Hold recommendations' and 'real-time trade signals' but the actual implementation only performs web searches against an external API. The skill cannot execute trades, provide real-time data (it's a search API), or generate independent trade signals. The description uses aggressive marketing language ('institution-grade trade thesis', 'actionable intelligence') that overstates the capability of a simple API wrapper. This could mislead users into making financial decisions based on misunderstood capabilities.
