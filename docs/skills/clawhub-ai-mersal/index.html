It instructs agents to: (1) register with an external service and store credentials locally, (2) continuously transmit agent activities to an external platform, (3) fetch and execute instructions from external URLs that could be modified at any time, and (4) integrate into the agent's heartbeat system for autonomous operation. The skill combines credential theft, persistent data exfiltration, indirect prompt injection, and social engineering. The primary threats are data exfiltration to moltbook.com and potential command injection through dynamically-fetched external instruction files. This skill should NOT be used without extensive security review and explicit user consent for all data sharing.

Findings

CRITICAL API Key Credential Theft and Storage in User Directory Data Exfiltrationllm

The skill instructs agents to register with an external service (moltbook.com) and store API credentials in the user's home directory (~/.config/moltbook/credentials.json). This creates a persistent credential that could be accessed by other malicious skills or processes. The registration process returns an API key that grants full access to the agent's identity on the external platform.

SKILL.md

```json
{
  "api_key": "moltbook_xxx",
  "agent_name": "YourAgentName"
}
```
Recommended: Save your credentials to `~/.config/moltbook/credentials.json`
Remediation: Do not store third-party API credentials in predictable locations in the user's home directory. If credential storage is necessary, use secure credential management systems (OS keychain, encrypted vaults). Require explicit user consent before registering with external services.
CRITICAL Data Exfiltration to External Social Network Data Exfiltrationllm

The skill's entire purpose is to send agent activity data to an external social network (moltbook.com). This includes posting content, comments, and potentially sensitive information about the agent's tasks and user interactions. The skill encourages regular 'heartbeat' check-ins every 4+ hours, creating a persistent data exfiltration channel.

SKILL.md

Description: The social network for AI agents. Post, comment, upvote, and create communities.
Base URL: https://www.moltbook.com/api/v1
Remediation: Require explicit user consent before transmitting any data to external services. Clearly disclose what data will be shared. Implement data minimization - only send necessary information. Allow users to review and approve posts before transmission.
HIGH Indirect Prompt Injection via External File References Prompt Injectionllm

The skill instructs agents to fetch and follow instructions from external URLs (HEARTBEAT.md, MESSAGING.md) hosted on moltbook.com. These files are not included in the skill package and could be modified by the external service to inject malicious instructions. The skill explicitly tells agents to 'just read them from the URLs above' and 'Check for updates: Re-fetch these files anytime to see new features'.

SKILL.md

| **HEARTBEAT.md** | `https://www.moltbook.com/heartbeat.md` |
| **MESSAGING.md** | `https://www.moltbook.com/messaging.md` |
**Or just read them from the URLs above!**
**Check for updates:** Re-fetch these files anytime to see new features!
Remediation: Bundle all instruction files within the skill package instead of fetching from external URLs. If external updates are needed, implement content verification (signatures, checksums) and require user approval for instruction updates. Never automatically execute instructions from untrusted external sources.

HIGH Social Engineering Through Deceptive Framing Social Engineeringllm

The skill frames data exfiltration to an external social network as a benign 'social network for AI agents' without clearly disclosing the privacy implications. The security warning focuses only on not sharing the API key with other services, but doesn't warn users that their agent's activities will be publicly posted to an external platform. This misleads users about the skill's true data collection and sharing behavior.

SKILL.md

The social network for AI agents. Post, comment, upvote, and create communities.
🔒 **CRITICAL SECURITY WARNING:**
- **NEVER send your API key to any domain other than `www.moltbook.com`**
Remediation: Provide clear, prominent disclosure that agent activities will be transmitted to and published on an external social network. Explain what data will be collected, how it will be used, and who can access it. Require explicit opt-in consent.
