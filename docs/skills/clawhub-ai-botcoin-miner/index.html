Findings

CRITICAL Unverified Remote Code Execution via curl|bash Installation Data Exfiltrationllm

The skill instructs the agent to download and execute a shell script directly from GitHub using 'curl | bash' without any cryptographic verification (no checksums, signatures, or hashes). This creates a critical supply chain attack vector where a compromised GitHub account, man-in-the-middle attack, or repository takeover could result in arbitrary code execution on the user's machine. The 'Quick install' method provides no security guarantees about the script's integrity.

SKILL.md

curl -fsSL https://raw.githubusercontent.com/happybigmtn/botcoin/master/install.sh | bash
Remediation: 1) Provide cryptographic checksums (SHA256) for the install script and verify before execution. 2) Use signed releases with GPG verification. 3) Pin to specific commit hashes instead of 'master' branch. 4) Include the install script content directly in the skill package for review. 5) Warn users about the security implications of remote script execution.
HIGH Unbounded CPU Mining Without Resource Controls Resource Abusellm

The skill instructs the agent to start cryptocurrency mining operations with no resource limits, monitoring, or automatic termination conditions. Mining is configured to run indefinitely in daemon mode with 'nice -n 19' priority adjustment but no CPU caps, time limits, or user confirmation for extended operation. The instruction 'scale up once you confirm everything is stable' encourages increasing resource consumption. This can lead to sustained CPU exhaustion, thermal issues, increased power consumption, and degraded system performance for other tasks.

SKILL.md

nice -n 19 botcoind -daemon -mine -mineaddress="$ADDR" -minethreads=2
# Tip: start with -minethreads=2, then scale up once you confirm everything is stable.
Remediation: 1) Implement strict CPU usage caps (e.g., cpulimit, cgroups). 2) Add automatic termination after a defined time period or block count. 3) Require explicit user confirmation before starting mining. 4) Monitor system temperature and throttle/stop if thresholds are exceeded. 5) Provide clear warnings about resource consumption and electricity costs. 6) Add a maximum runtime parameter with default limits.
HIGH Network Exposure via Hardcoded Seed Peers Without Verification Data Exfiltrationllm

The skill configures the agent to connect to hardcoded external IP addresses (95.111.227.14, 95.111.229.108, 161.97.83.147) on port 8433 without any verification of peer identity, certificate validation, or reputation checking. These connections are established automatically when the daemon starts. This creates risks of: 1) Connecting to malicious nodes that could serve invalid blockchain data, 2) Network traffic analysis and fingerprinting, 3) Potential exploitation if the P2P protocol has vulnerabilities, 4) No mechanism to verify these IPs are legitimate Botcoin network nodes.

SKILL.md

addnode=95.111.227.14:8433
addnode=95.111.229.108:8433
addnode=161.97.83.147:8433
Remediation: 1) Implement peer verification mechanisms (certificates, signatures). 2) Use DNS-based peer discovery instead of hardcoded IPs. 3) Provide peer reputation/trust scoring. 4) Allow users to review and approve peer connections. 5) Implement connection encryption and authentication. 6) Document the ownership and trustworthiness of seed nodes.
